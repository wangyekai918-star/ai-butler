1920px、1440px 下四项指标保持同一行；1350px 以下采用两列指标，趋势和明细上下排列、排名上下排列，保证文字可读。主体在内容区内滚动，顶栏、左侧导航和页签保留。

### 安全评估

以 Figma `1650:10649` 为列表组件参考：16px白卡内边距与圆角、34px筛选控件、浅蓝48px表头、60px数据行、12px表格圆角和28px分页按钮。业务字段按v22原型适配，不复制参考设计中的促销业务内容。

1. **筛选区**：评估日期、车架号、总分、健康状态、车辆大类、判定品牌、车系通用名称共7项，支持查询和重置。默认评估日期2026-08-17、健康状态高危；日期必填，车架号支持不区分大小写的包含匹配，总分精确匹配（包括0分）。大类联动品牌，品牌联动车系，自动清空不匹配的已选项。
2. **评估列表**：保留原型的12列字段，展示日期、车架号、统计类型、总分、健康状态、城市、车辆大类、品牌、车型、判定危险项、电池健康评分和操作。表头及右侧操作列固定；横向、纵向滚动均在表格内部。高危、亚健康和健康使用文字与红、橙、绿标签共同区分，较长车型可悬停查看完整名称。
3. **分页与空态**：每页10条，默认20条高危分两页；选择全部可浏览480条。查询后返回第一页，结果为0时展示空状态并隐藏分页；记录数和页数由过滤后的数据计算。
4. **评估详情**：点击行内操作打开该车辆详情，展示车辆身份、日期、状态、总分、电池健康评分、原型的7项指标及判定危险项。支持关闭按钮和Escape，关闭后焦点返回对应行操作。

演示数据统一使用`DEMO-VIN-0001`等虚拟编号，不复制原型车架号。共480辆、36款车型：乘用车408、货车60、客车12；健康432、亚健康28、高危20。高危车型Top5和大类数量与车辆防护页一致。所有记录均为2026-08-17的评估，统计类型沿用原型的`VIN`；选择其它日期显示空态，不模拟不存在的历史记录，页面顶部时间范围仍为静态。

高危得分与指标采用原型5组模板；其它记录补充为本地UI示例。状态为显式预设值，未实现业务判定算法；详情单项得分≤1的红色强调仅沿用原型示例，不代表正式安全阈值。原型中的重复记录与不一致计数没有沿用；未扩展购买流程、导出或后台服务。

筛选项按容器可用宽度自动排列、换行，不再固定每行数量；标签使用自然宽度、图文间距8px，常规输入框180px、车架号和车系200px、总分120px、健康状态160px。宽屏可将全部条件与操作放在一行，空间不足时自然换行，查询/重置按钮紧跟最后一个字段。表格保持字段可读宽度，不挤压所有列强行适配。只在当前充电安全目录内增加内容。

### 防护预警

1. **顶部概览**：高危预警82次、严重预警100次、一般预警54次、阻断68次；四张白卡独立横排，16px内边距和圆角、12px图文间距。使用用户提供的高危、严重、一般、阻断四张透明PNG图片，204×204px原图按68×68px显示，移除灰色占位背景。主数字36px Oswald，高危和严重数字分别使用红、橙；一般预警和阻断次数使用常规黑色#111827。
2. **快捷筛选**：点击级别卡片同步筛选列表与下拉选项，再次点击取消；点击阻断卡片查看已阻断记录，再次点击返回全部。选中卡片使用蓝色细框和浅蓝底；键盘可聚焦并操作。
3. **条件筛选**：预警起止日期、订单编号、预警级别；查询和重置均接通。日期范围包含首尾日期，结束日期早于开始日期时提示修正；订单支持不区分大小写的包含匹配。阻断筛选可与下拉的预警级别组合查询。卡片数量按已查询的时间、订单条件统计，不因级别筛选缩减其他级别数值。
4. **预警明细**：按原型保留发生时间、订单编号、结束原因、车型、电站名称、终端名称、预警类型、预警级别、是否阻断共9列。筛选与表格放在一个白卡里，不重复添加“防护预警列表”可见标题；复用安全评估的34px控件、48px浅蓝表头、60px数据行与分页组件。表头固定，表格内部横向、纵向滚动，长字段省略并可悬停查看全文。
5. **分页和空态**：每页10条，共236条虚拟预警记录，默认24页；查询或切换快捷筛选后返回第一页，零结果显示空态。最后一页显示6条。

顶部三档预警合计236次；68次阻断是预警记录的一个子集，不能再与236相加。日期与看板一致，为2026-08-08至2026-08-14；每天预警数29/34/31/39/32/36/35，阻断数8/10/9/12/9/10/10，直接复用看板趋势数据。预警类型与车型取原型示例类别，记录数量采用当前小规模演示值；订单统一为`DEMO-日期-序号`，电站使用“示例充电站 A”等，不复制原型身份或定位信息。

原型筛选项名为“预警类型”，实际选项是高危、严重、一般；此处改为“预警级别”，与表格中的具体预警类型区分。原型的时间、订单输入未参与实际过滤，此版已接通本地筛选；原型顶部大数值和8条明细不一致，此版统一为当前236条示例。没有新增导出、订单跳转、阻断控制或真实业务操作。

1350px以下顶部概览切换两列。筛选项按可用宽度自动排列、换行，标签采用自然宽度，起止日期各180px、订单编号200px、预警级别160px；查询/重置紧跟条件，宽屏不再拉长输入框。表格保留可读列宽并在内部滚动。已核验1024、1280、1440、1920宽度，查询、重置、快捷筛选、末页和空态均可用。

## 文件

- `充电安全.html`：四个页签的页面结构、筛选和详情弹窗、示例数据与趋势日点。
- `style.css`：外壳、指标、图表、明细、排名、车辆防护、安全评估与防护预警样式，按模块分区。
- `app.js`：本地 SVG 图表绘制、悬停与键盘提示、窗口适配、页签切换和链接定位，以及评估/预警示例数据、筛选、分页与评估详情。
- `assets/`：本地 PNG、SVG 和 Oswald 字体，运行时不依赖外部 CDN。
- `.history/`：修改前备份、图标原始生成图和验证记录。

统一提示词要求：轻3D、柔和材质、左上方柔光、少量侧视角、透明背景、小尺寸清晰，无文字和装饰元素。完整英文提示词保存在 `.history/gateway-icons/prompts.json`，原始生成图也在该目录。生成时仅提交图标造型描述，没有上传原型、业务记录或页面截图。

当前AI防护图标按用户要求直接从紫色盾牌进行色相调整，保持轮廓、透明度和白色对勾不变，并调深绿色提升小尺寸下的辨识度；原图保存在`.history/`。

环比按最新要求统一为上升绿色、下降红色；使用Figma原始8×8三角SVG：`assets/change-up.svg`（节点`4:188`）和`assets/change-down.svg`（节点`4:217`），箭头右侧数字统一使用600字重。按用户最新要求，AI防护次数改为下降2.36%的红色示例，使用`metric-change--down`与下降切图；其余环比保留原有演示值。风险等级颜色独立保留。趋势右侧指标宽度调整为240px。

排名序号字体从Google Fonts引入Anton Regular，已保存为本地`assets/fonts/Anton-Regular.woff2`，通过`@font-face`加载；授权文件为同目录`Anton-OFL.txt`，预览不依赖外部字体网络。
