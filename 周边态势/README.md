# 周边态势

AI 管家的独立一级模块，与「事件详情」「充电安全」同级。当前版本展示范围入口、战略定位、格局变化和竞争力排行榜。

## 当前范围

- 复用 AI 管家的 Logo、顶部公司区域、消息、反馈和用户信息样式。
- 复用现有侧栏，当前选中「周边态势」。
- 沿用 60px 顶部栏、218px 侧栏、12px 页面外边距、14px 模块间距和浅灰底白色圆角容器。
- 右侧顶部按设计稿展示「深圳湾海岸大学公共站」与「附近3km」，仅呈现入口外观，不增加交互。
- 左侧「竞争力分析」默认展示战略定位：ECharts 四象限气泡图、竞争格局 / 压力来源 / 建议关注三张分析卡和通栏 AI 分析总结。「战略定位 / 格局变化」位于卡片右上角，与标题同排，可切换；雷达对标暂不制作，不展示 Tab 入口。
- 气泡支持悬停查看场站明细：当前气泡高亮，其余气泡淡化，详情卡按气泡的数据坐标固定在其旁边，优先右侧、空间不足时左侧避让；不跟随鼠标或内部文字的命中边界移动，避免气泡内部移动时左右跳动。悬浮卡不接收鼠标事件，移出气泡立即关闭，不会因指针停在悬浮卡区域而继续显示或挡住其他场站。问号支持悬停或聚焦查看大小说明。三张分析卡的标题及箭头可打开详情抽屉；支持关闭按钮、Escape 和点击遮罩关闭。详情仅展开截图中已有信息。
- 宽屏采用图表在左、三张分析卡在右的布局；可用宽度不足时，分析卡移到图表下方，排行榜移到主分析区下方。
- 右侧「竞争力排行榜」按设计稿展示综合排名、分数、星级、距离，以及本站的优势项和待提升项；五个排名维度和底部完整榜单入口先作静态展示。
- 「我的竞争力」及「周边场站分布地图」已有前端实现且本次无修改，当前 Demo 不重复搭建，也不添加对应占位块。
- 排行榜数据沿用上一轮 Figma：可见 7 条、本站第 5 名、82 分，底部显示共 12 个场站。尚未接入接口，其他维度的排名未补造；格局变化复用这 7 条最新数据，并补齐其余站点的演示样本。

## 战略定位数据口径

- 气泡数值及分析结论的数据依据是用户本次提供的战略定位截图（`codex-clipboard-ff02f67c-1e36-4944-bc86-115fd36c6f6c.png`），不采用此前下载的旧 HTML 原型。悬浮字段、交互及状态名称依据 2026-10-13 在线核对的 PRD《018AI管家周边态势竞争力分析》第 2 节。
- 气泡得分使用截图内可见数字；横坐标按刻度近似还原，提示中的价格标注为“约”。13 个竞品气泡按用户要求配置不同的虚拟场站名称，统一在 `app.js` 的 `demoStationNames` 中维护；不代表真实场站或截图中的站点对应关系。终端数量为虚拟数据，气泡面积随终端数变化，数量按原图尺寸比例配置。
- 截图本身存在差异：本站气泡为 65 分、位置约 1.02 元/kWh；文字结论为 58 分、0.78 元/kWh。当前按截图分别保留，不自行推断或统一。原有排行榜为独立示例数据，不与这次截图强行联动。
- 四象限分界按截图为价格 1.00 元/kWh、得分 50 分，不将文字结论中的均价、均分误用为分界。
- 本站名称置于气泡内部，得分采用 22px Oswald。悬浮卡采用站名、状态标签和双列字段：距离、终端、平均价格、最新一次价格变动、综合得分、所选范围内排名。原参考图的“近7天价格”已更名，“单桩运能”不展示，底部雷达对标入口按 PRD“暂时先不做”处理。
- 终端类型数量为 0 时不展示该类型；最新价格变动支持日期与前后价格；排名字段读取顶部的 1 / 3 / 5km 范围。当前顶部入口仍静态展示 3km，不新增范围切换交互。
- 按用户要求补齐全部 14 个气泡的虚拟距离、终端明细和调价记录，维护在 `demoStationDetails`。终端总数由超/快/慢求和，调价后价格与当前气泡一致；新站显示上线日期及“暂无调价”。1/3/5km 排名由本组演示样本按距离筛选、得分排序计算，不代表真实范围总数。截图得分与价格不变。
- 最新 PRD 的状态为“本站 / 降价 / 涨价 / 新站 / 正常”，将旧截图中的“新价”统一更正为红色“涨价”；其余现有点位、分析文案和排行榜数据保持独立，不在本轮悬浮卡修改中重算。

## 格局变化：规则与演示数据

- 功能依据 2026-10-13 在线核对的 PRD《018AI管家周边态势竞争力分析》第 3 节及其中的趋势图。用户确认站点统一使用当前排行榜，不采用旧 HTML，也不直接搬用 PRD 图片中的科苑路等站名。
- 展示固定示例日期 **2026-10-07 至 2026-10-13** 的每日竞争力排名；先按每一天的综合得分对全体站点排序，再筛选竞争圈。切换竞争圈不会把入选的 8 站重新编号为 1–8 名。
- **最新一天与右侧排行榜一致**：前 7 站的名称、分数、距离由脚本直接读取 `.rank-item`；本站第 5 名、82 分。右侧第 6 名的长站名仍保留，图表终点做截断，悬浮展示全名。
- 右侧只展开了总计 12 站中的 7 站。为演示两种竞争圈的差异，补充云杉路、星河广场、青岚科技园、锦程大道、望湖中心 5 个虚拟站点，最新分数均低于已展示第 7 名。
- **前 6 天的得分、全部调价/上线事件、价格、终端明细、单桩运能和补充站点都是 UI 演示数据，不是 PRD 实测值或线上数据。** 维护位置为 `app.js` 的 `trendFixtures`、`extraTrendStations`、`trendEvents`；接入接口时整组替换。战略定位沿用既有截图口径，本轮不改其气泡或分析结论。
- 默认按名次。PRD 正文默认说明与表格/图片存在差异，此处遵循正文“默认按名次”。按名次圈定本站所在的 8 站名次段；按距离选择本站及最近的 7 个竞品。总站数不超过 8 时全部展示。底部实时说明筛选范围及未展示数量。
- 曲线颜色按对应日期分段：正常蓝 `#315EEF`、降价绿 `#05B37F`、涨价红 `#E34C4C`、新站紫 `#9852EF`。最后一次价格动作生效后沿用该状态，下一次动作更新颜色。本站以较粗曲线、节点和终点标签区分，仍遵循事件色义。
- 事件标签对应日期竖虚线，展示“站名 + 涨/降价 + 前后均价”或“站名 + 上线”。同日多事件自动分行，宽度变化时重新避让。
- 迎宾街示例于 10-13 上线，上线前无分数或排名，图上不补画历史曲线。终点显示站名、距离和最新分数。
- 右侧站名、距离和分数的整块文字区域（包括两行间的空隙）支持悬停查看整站详情，并联动高亮对应曲线。曲线上下各约 12px 范围均可悬停查看，视觉线宽保持不变；多条曲线接近时选择距离最近的一条，交叉点同距时保持当前场站。悬停任何一段曲线/节点时，该站所有历史分段一起高亮，其余场站淡化；移出后恢复。高亮、淡化及恢复均采用与战略定位一致的 300ms cubic-out 过渡；快速切换场站从当前状态接续，系统开启减少动态效果时不播放过渡。按用户最新截图调整为整站详情：悬停曲线路径任意位置或节点均直接展示该站最新的终端总数及超/快/慢拆分、平均价格、单桩运能、综合得分、7天排名走势，不再展示指针所在日期的单点参数或距离。起止排名使用窗口首日和末日；排名上升用绿色、下降用红色，持平中性灰；窗口内新上线的站点展示“新站上线 · 第N名”，不虚构首日名次。数量为 0 的终端类型不显示。悬浮窗不拦截鼠标，移出曲线立即关闭。右侧终点的分数与“分”统一使用 11px 普通字体、600 字重及对应状态色，与距离同字号。
- 使用本地 ECharts 的 SVG 渲染。图表宽度不足 660px 时只在图表区域横向滚动；高度根据事件标签行数和实际名次跨度自适应。页签切回或容器变宽时重新计算尺寸，隐藏图表不按 0 宽重绘。

## 文件

- `周边态势.html`：页面结构。
- `style.css`：当前模块的全部样式，后续按模块注释分区维护。
- `app.js`：战略定位截图数据、格局变化演示数据、每日排名、竞争圈筛选、ECharts 图表、页签切换、自适应尺寸和分析详情交互。
- `assets/`：本模块使用的本地 Logo、独立 SVG、字体与 ECharts。

图标和 Logo 复制自现有 AI 管家模块的 Figma 导出资源；周边态势图标沿用原形状，仅改为选中态主色 `#315EEF`。运行时不依赖其他 Demo 或远程图标地址。
