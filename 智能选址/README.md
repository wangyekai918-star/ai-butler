## 当前交互约定（以此节和文末最新修订为准）

- 左侧菜单顺序：价值评估 → 智能选址 → 系统托管。
- 配置页左侧为范围/位置地图，右侧为建站/评估需求；结果页保持地图位置和面板宽度，右侧表单替换为结果。修改条件返回配置并保留输入；结果页不能直接修改范围。
- 场地地图直接点击选点，搜索提示为「搜索地点名称或点击地图选点」；叉号同时清空搜索和点位。连续选点只保留一条最新提示。
- 两类完整报告共用顶部通栏、左侧对象卡片、中间独立滚动正文、右侧编号目录；区域报告08/09同时选中，场地报告八章独立定位。
- 「导出全部报告」导出本次结果的全部推荐区域，选中态仅控制地图联动；详情页「导出报告」导出当前对象。导出为自包含HTML，含字体、图片和ECharts静态图，根节点允许自然滚动；旧下载文件需重新导出以获得修复。
- 没有「保存草稿」按钮。保留原型草稿状态及历史恢复，分析任务保存在浏览器 localStorage，不跨设备同步。
- 地图使用用户提供的静态底图，不实现SDK缩放拖动；内置行政区候选仅有济南，按区县过滤，无候选时显示空结果。未接入地图服务、真实选址算法或业务后台。
- 年租金未填为null，不回显为0；明确填0按0计算，未填仍沿用模型估值。预算/规模/评分和财务参数为演示口径，研发需以产品与后端定义为准。
- 下文包含历次迭代记录，旧布局描述与本节冲突时以本节为准。

## 已实现的本地演示

1. 范围选址：省市区县级联、单一圆形绘制、重画替换、退出与删除、类型与建设规模联动、配置收展、加载反馈。
2. 分析结果：地图与候选列表联动、五个原型候选区域、综合评分降序、图层开关、需求/价格热力互斥。修改条件后明确标注为上次结果；更新分析后替换，避免将旧结果当作新范围的推荐。
3. 意向场地：真实区县检索、地图选点、重选、面积估算规模、基础输入校验、已有场地与新建场地评估。
4. 报告：八个共同章节；区域报告额外有候选对比和区域切换。两类报告均有章节目录；报告返回对应工作区。
5. 图表：本地 ECharts 雷达、价格分布、规模分布、24小时车流、供需曲线和客群环形图；支持悬浮查看、图例切换及容器自适应。图表数据取原型示例。
6. 方案调整：编辑终端数、功率、服务费、校准系数及费用参数，重新测算，并同步报告摘要和建议。
7. 任务：发起范围分析生成任务、完成后保存结果；场地报告也记录到任务列表。通过本地 localStorage 演示保存和恢复，恢复对应配置、范围和结果。页面刷新中断的分析标为失败，避免冒充后台仍在计算。
8. 导出：单个区域报告、场地报告和全部区域报告导出为自包含 HTML，包含本地图片、字体与图表静态快照。可在浏览器打开并打印为 PDF；不声称存在后端 PDF 服务。

## 研发接入与未覆盖范围

- 当前为高保真前端页面，用户确认使用虚拟街道地图，不接高德 SDK；位置、道路及POI用于展示，不代表真实地理坐标。未接入真实地图服务、后台选址算法或投资预测。顶部及全局侧栏维持既有静态外壳。
- 示例任务仅保存在当前浏览器和当前源下，不跨设备同步。正式接入需用任务 ID 关联配置、分析状态、候选集合及报告版本。
- 候选列表依 PRD 按综合评分排序，不沿用原型中隐藏的「回收期达标优先」规则。
- 两类评估提交后统一进入任务列表，通过本地存储演示保存与恢复。已移除自行补充的“保存草稿”入口及手动保存逻辑；保留原型中的草稿状态与历史任务恢复能力。
- 原型的每30平方米估算一桩、面积为空默认8桩、预算档位影响示例评分、静态收益模型等仅为原型规则；评分权重、等级阈值、成本/现金流口径由产品与后端确认。不能把这份前端代码当成生产决策算法。
- 「待补充」成本在原型中按0参与计算，示例报告沿用此口径并保留提示，不代表费用实际为0。
- 重卡路线选址的路线条件仍待定义，目前保留选项并说明待完善，阻止用区域分析冒充路线分析；区域选址可完整操作。两类场站的真实数据适配待业务模型定义。
- 条件研判的「去补充」维持原型提示入口，未接入工单、上传及核验服务；未实现材料审批或将待核验项自动改为通过。
- 页面中的「实测／模型估算」为原型来源分类，不代表已接入真实采集；按用户要求，界面不显示“示例”标记，实现边界在本文件交接。
- API分析失败、真实空结果、导出权限、网络重试及后台回调需接口接入后补齐。当前导出支持错误提示，无候选集合时阻止导出。

### 条件设置与结果查看分离

提交后进入只读结果状态：地图栅格位置、宽度和提交前高度保持不变，范围控件锁定；右侧380px需求面板整体替换为同宽结果列表。条件摘要仅在右侧列表顶部回显，不再占用全宽顶部。地图候选区域仍可选择，但不允许在结果状态改范围或需求。地图左上角“返回”和右侧“修改条件”均返回完整条件设置，保留原选择；再次提交才刷新结果。窄屏仍先地图、后右侧内容。

推荐区域样式：地图排名为独立蓝色序号块，名称与评分标签按文字实测宽度生成，选中区域右上角显示对号。右侧列表名称与评分突出，服务费、规模、投资额、回收周期采用两列字段；当前选中状态与地图联动。桌面结果列表独立滚动，不撑高地图；窄屏自然展开。

地图区域标签使用逆向缩放抵消SVG地图比例，文字固定显示12px，序号20×20px正方形，名称标签同高20px，对号半径8px；屏幕变宽时不随地图放大。

### 导出HTML的独立滚动样式

导出文件虽然复用页面的组件CSS，但必须覆盖应用壳的 `html,body{height:100%;overflow:hidden}`：导出时设置根节点高度为auto、允许纵向滚动，正文容器自然展开，不依赖应用内部滚动区域。区域单份、场地单份及区域报告合集共用该覆盖规则。旧下载文件不会自动更新，修复后需重新导出。
