# 促销事件

独立的促销事件详情页，复用「经营风险 · 促销策略」的通用外壳、事件生命周期、决策生成和评估复盘。原页面保留。

[在线页面](https://wangyekai918-star.github.io/ai-butler/事件详情/促销事件/促销事件.html)

## 结构与样式

- 分析顺序：转化时机分析 → 电站体验复核 → 用户群体分析 → 预计转化人数 → AI分析结论。
- 上排三张分析卡，下排人数预估与独立AI结论框；下排外层随较高内容自动等高，数字在标题下的空间内垂直居中。内容宽度不足900px时按相同顺序单列展示。
- 沿用AI管家配色、浅蓝横幅标题、线性图标与Oswald指标字体。预计转化人数直接展示在卡片内，无嵌套灰框。
- 标题问号移入或聚焦显示原型说明，移出、失焦、Esc或滚动时关闭。
- 用户构成左侧使用本地ECharts饼图，右侧为图例与占比条，无灰色底框和重复标题。饼图悬浮显示提示并高亮扇区，图例移入联动。进度条8px，百分比16px并与对应条形同色；数字紧随条形末尾，条长统一以100%为基准。

## 字段和数据来源

分析区字段、数据、说明、分析判断和结论来自用户提供的产品原型截图；用户后续确认的标题及样式调整优先。

| 字段 | 值 |
| --- | --- |
| 场站 | 中国石化济南莱芜第44加油站充电站 |
| 复充周期 | 首充后3~7天 |
| 近7天差评数环比 | +3.2% |
| 体验状态 | 体验正常 |
| 私家车用户占比 | 61% |
| 网约车用户占比 | 31% |
| 其他用户占比 | 8% |
| 预计转化人数 | 102人 |

分析数据集中在HTML中的`promotion-analysis-data`，饼图、进度条和指标从同一份数据生成。修改数据时需同步核对静态判断与结论文案，避免显示不一致。

原型截图仅覆盖分析过程。事件信息做促销场景适配；决策和复盘沿用原促销策略模板：158人、2000元预算、102张券、45人完成转化。预计转化人数与发券数量为独立口径，不互相推导；这些阶段不能视为已按分析截图核验。

## 开发与运行

HTML、`style.css`、`app.js`同级分离，资源在本页`assets/`内，不跨Demo引用。ECharts在`assets/vendor/echarts.min.js`，无需外部CDN。页面用于UI演示，不执行真实发券或业务提交。

在仓库根目录运行`python3 -m http.server 8767`，打开`http://127.0.0.1:8767/事件详情/促销事件/促销事件.html`。
