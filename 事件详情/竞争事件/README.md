## 当前交付

以用户提供的《AI管家事件详情 PRD》4.4、5.1、6.2 和 `竞争分析.html` 为业务参考，视觉沿用 [AI管家UI风格规范](../../AI管家UI风格规范.md)。用户后续明确修改优先，差异记录在走查记录中。

- 单站：BP快速充电站价格变化触发济钢充电站竞争分析，基于全部有效竞品的事件时点快照。
- 四阶段：事件信息、六步事件分析、策略生成（已生成/已完成）、评估复盘（已复盘）。仅保留一组完整结果。
- 宽屏步骤并排，关系、价格、需求指标均为2×2宫格；窄屏自动减少列数。
- 分时推荐宽屏为左概览、中分布、右明细；细色带6px，外置Oswald数字随容器宽度为16–24px。增用#E21818，减用#05B37F，保持现价为灰色。
- 明细标题右侧的眼睛按钮切换保持现价时段，展开后按时间顺序排列。
- 右侧生命周期支持定位、滚动和历史锚点。03/04同排时联合高亮，分行时独立高亮，页尾能进入最后一组。
- ECharts 本地绘制累计效果指数，支持悬浮解释、图例开关及容器自适应。
- 顶栏、侧栏及返回维持静态；无后台接口、真实策略执行、通知发送或定价算法。

## 接口接入约束

- CR：≥0.70核心；0.45–0.70重要；0.25–0.45一般；＜0.25弱关系，上限不含。
- CPI：＜35低，35–65中（含端点），＞65高。指针位置依据CPI/100；TOP3按Aj倒序，最多3个，不强制加入触发站。
- 价格差：≥+0.02偏高，≤−0.02偏低，其余持平。价格保留两位、CPI和威胁力保留一位、CR两位。
- 需求比值：＜0.95低迷，0.95–1.10正常（含端点），＞1.10旺盛。
- 无机会、无可执行时段、多站权限、待确认/取消/回调等其他状态为后续接口范围，本页未提供状态切换器，不应声称已覆盖。
- 推荐价格由后端提供，前端仅展示差值、时段和结果；不可用Demo前端生成业务推荐价。
- 结束态复盘用日节点；各节点口径为执行开始至该节点的累计值。图中指数=累计实际值÷同期累计评估基准×100，不是每日独立值或实际度数。
