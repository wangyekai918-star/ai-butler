## 分时调价色阶

全天分时调价分布的数字、细色带和图例使用相对色阶：上调红、下调绿，**分别按当前展示数据中上调、下调的最大绝对幅度归一化**，不按固定金额设档，也不将涨跌混在一起取最大值。

- 上调最大幅度使用规范红 `#E21818`；下调最大幅度使用规范绿 `#05B37F`。
- 同方向其他幅度按比例向白色混合：比例 = 当前绝对幅度 / 该方向最大幅度；混白量 = 0.72 × (1 − 比例)。幅度越小颜色越浅。
- 当前示例 +0.03 为最深红，+0.01 为浅红；−0.02 为最深绿，−0.01 为浅绿。某方向仅有一个幅度时，该幅度使用最深色。
- 数字、色带与图例复用同一颜色计算；数据更新后需重新计算该方向最大值及所有对应颜色。
- 维持现价用灰色，不参与归一化；某方向无数据时不计算该方向色阶，避免除零。
- 此规则用于分布图，明细表及策略结果保留标准红绿色以保证阅读清晰；色阶是展示规则，不是业务推荐规则。

## 接口接入约束

- CR：≥0.70核心；0.45–0.70重要；0.25–0.45一般；＜0.25弱关系，上限不含。
- CPI：＜35低，35–65中（含端点），＞65高。指针位置依据CPI/100；TOP3按Aj倒序，最多3个，不强制加入触发站。
- 价格差：≥+0.02偏高，≤−0.02偏低，其余持平。价格保留两位、CPI和威胁力保留一位、CR两位。
- 需求比值：＜0.95低迷，0.95–1.10正常（含端点），＞1.10旺盛。
- 无机会、无可执行时段、多站权限、待确认/取消/回调等其他状态为后续接口范围，本页未提供状态切换器，不应声称已覆盖。
- 推荐价格由后端提供，前端仅展示差值、时段和结果；不可用Demo前端生成业务推荐价。
- 结束态复盘用日节点；各节点口径为执行开始至该节点的累计值。图中指数=累计实际值÷同期累计评估基准×100，不是每日独立值或实际度数。

### 接入时必须同步更新

建议以同一个 CPI 数据及等级映射驱动以下内容，避免各处分别写死：

1. `.cpi-number`：CPI 数字，保留一位小数，沿用 Oswald 数字字体。
2. `.pressure-level`：图标路径、等级名称、状态说明及对应颜色。
3. `.cpi-pointer`：位置为 CPI/100 对应的百分比；浮标显示“当前 {CPI}”，浮标、三角和圆点颜色同步。靠近 0、100 时避免浮标溢出。
4. 当前阶段的 `.stage-badge` 和 `.stage-foot`：等级标签、结论中的 CPI 与等级及状态色同步。
5. `.cpi-meter` 的 `aria-valuenow`、`aria-valuetext`：同步真实展示值和等级，不能保留“31.8，低压力”。

刻度条始终保留绿、橙、红三段，分界点为 35、65；只移动当前指针，不要把整条刻度改成当前等级颜色。主要竞争来源 TOP3 由接口数据按 Aj 倒序展示，不能依据 CPI 或示例值自行编造；CPI 也不能简单等于 TOP3 之和。

- 分别用 31.8、50.0、80.0 检查三个等级的数字、图标、文案、颜色、指针和结论是否一致。
