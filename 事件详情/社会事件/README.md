## 文件

- `社会事件.html`：公共页面结构、电站选择面板及本地原型数据。
- `style.css`：全部样式，继承已确认的页面外壳与组件，末尾为社会事件样式。
- `app.js`：电站权限范围展示、选择、检索、分页、单站内容渲染及生命周期导航。

## 布局与交互

事件信息保持全局事件视角，不因切换电站而改变演唱会名称、活动时间等事实。事件信息标题与字段表格间距为 12px。在事件信息与分析过程之间放置「电站分析范围」，直接铺在页面灰底上，无白卡、圆角或外层内边距。普通 13px 的站点统计紧跟范围标题，间距 12px；下方间距 8px 平铺电站标签，点击即可切换。

电站标签按照实际可用宽度和渲染后的文字宽度自动排列，不限制固定站数。全部放得下时全部展示，隐藏「更多电站」；放不下时，为「更多电站」预留宽度，展示当前一行能容纳的电站。窗口缩放和字体加载完成后自动重新计算。选中项使用蓝字、浅蓝底和蓝色细边框，始终保持可见；若从完整列表选中的电站处于隐藏区域，则替换末尾可见项以显示当前站。标签高 34px、间距 8px。

仅当当前宽度无法完整展示所有电站时，标签末尾提供「更多电站」。点击后打开原生 Popover 面板，不增加遮罩；支持区域筛选、名称或编号检索、每页 6 条分页，列表同时展示站名/区域、影响判断和建议方向。空间不足时面板在上方显示，列表内部滚动。再次点击更多电站、点击外部、Escape 或关闭按钮均可收起。选择即生效，关闭面板并返回更多电站入口焦点。搜索为空时有明确空状态。所有入口均只操作当前可查看列表。

分析过程、决策生成、决策执行评估及决策复盘在切换站点时同步更新。分析标题带当前电站名称，吸顶位置为 60px 导航下方 12px，便于滚动时确认所看站点。右侧生命周期只高亮当前阅读阶段。

单站分析先做「外部事件影响评估」，只有进入机会评估的电站才展示机会条件、经营健康、机会强度与预测、竞品价格空间、收益测算。前四项横排，分析过程以 AI判断结束，已移除额外添加的通用「建议动作」列表；通知提醒、保持价格与持续观察等方向保留在 AI判断中。

收益测算改为候选方案卡片：每张卡对应一个调价幅度，按「调价幅度与结论 → 预测服务费收入及变化率 → 预测充电量及变化率」组织。不调整方案作为基准，收益最大方案用浅蓝底和蓝色边框突出。保留原表全部数值及结论，变化率均相对不调整方案；卡片只用于比较，不增加点击或执行操作。宽屏最多一行四张，分析容器宽度不超过 880px 时两列，不超过 440px 时单列；间距 8px，内边距 12px。描述采用 13px / 18px，保留指标数字 Oswald 和中文独立字体。

03 决策生成与 04 决策执行评估并排，间距 14px；小窗口顺序排列。05 决策复盘独立放在下一行。调价详情采用字段宫格。分时价格方案按“电费 / 服务费 / 综合价格”分行、“调价前 / 调价后”分列，在较窄决策卡内保留原型全部价格信息，避免七列横向挤压。

04 决策执行评估展示执行评级、执行期间累计充电量/用户数/服务费收入及变化率，再展示执行趋势。服务费收入为主指标，绿色；充电量、用户数为中性灰。

05 决策复盘展示最终评级、AI复盘结论，以及原型中的三项增减影响：AI创造价值（服务费收入影响）、充电量影响、用户数影响。AI创造价值为浅紫底，其余两项中性灰。默认站示例为 +354元、−120度、−5人，和第四阶段的累计实际值区分开。宽屏下结论与三项影响并排；较窄窗口上下排列。

## 权限与业务分支

依据 PRD 4.3、4.5，实际可展示范围为：**事件关联站点 ∩ 当前用户有权限站点**。统计、快捷入口、检索和分页均以此集合为准。

- 多于 1 个：展示筛选，支持切站。
- 恰好 1 个：隐藏筛选，直接展示该站闭环；分析标题仍显示站名。
- 0 个：显示无权限空状态，不渲染电站业务分析、决策及复盘，不显示相关生命周期入口。

以下是原型给定的代表性站点：

| 电站 | 场景 | 页面处理 |
| --- | --- | --- |
| 奥体中心东站 | 存在调价空间 | +0.03 元/度；完整决策与已复盘结果，评级优 |
| 经十路快充站 | 机会成立、价格空间不足 | 保持价格，不进行收益测算，不显示尚未生成的决策、执行评估和复盘 |
| 龙奥快充站 | 存在调价空间 | +0.01 元/度；独立经营数据，评级良 |
| 体育中心南站 | 建议通知 | 展示运营提醒建议，不虚构通知发送记录 |
| 奥体西路站 | 预计需求下降 | -18.0%，红色变化值，展示通知建议 |
| 工业南路站 | 持续观察 | 不生成经营动作，不显示决策、执行评估和复盘 |

通知类策略按 PRD 不展示经营效果复盘。本原型仅给出部分站点的「通知建议」，没有通知生成记录、内容、对象或发送时间，因此本版没有把建议伪装成“已生成 / 已发送”的通知策略。以后接入真实通知记录时，应展示独立通知策略模块。

本页的授权数组只模拟原型状态，**不是实际权限系统**。正式接入必须由后端鉴权并仅返回允许查看的数据，不能把所有站点数据下发后依赖前端过滤来保障权限。

## 数据及口径

- 原型：社会事件_权限站点筛选_.html（本地原型，不随仓库分发）。
- AI管家事件详情 PRD（内部需求文档）。2026-09-14 校验元信息，版本与当天已读取内容一致；依据 2.1、3.2、4.3、4.5、5、6.2。
- [UI 风格规范](../../AI管家UI风格规范.md)及前三版已确认的 12px 内边距、8px 内部模块间距、14px 外部模块间距、渐变标题、AI结论框、数字字体。

12 个站点、9 个受影响站点及所有站点指标沿用原型。受影响标记来自业务数据，没有根据前端涨幅阈值重新分类；因此部分涨幅较低的站点仍标为“受影响”。

原型的收益测算表通过固定示例公式生成候选数据，本版在生成页面时按同一公式计算后写入 JSON，前端只负责展示。不是实际量价模型，也不会发起调价请求。奥体中心东站候选模型中的基准收入与复盘给定基准不一致，本版分别保留原型模型结果和复盘结果，不强行联算；正式对接需产品确认两个模块的时间范围与基准。

2026-09-14 用户明确修订：社会事件保留原型独立的执行评估与最终复盘，采用五个生命周期节点。该结构不沿用 PRD 6.1 通用合并模板，其他三个 Demo 保持原有四阶段。页面标题和右侧导航一一对应；旧 #execution-review 链接兼容跳转到第四阶段。未生成的后续阶段隐藏，而不是重复放空卡；执行评估有数据时可展示，最终复盘必须已完成并有价值结果才展示。

执行评估与最终复盘已拆成两个独立模块，执行趋势只出现在第四阶段；已移除横向效果对比柱图。图表纵轴是从策略生效起的累计经营结果相对同期基准的变化率；图例与悬停/键盘提示区分服务费收入、充电量及充电用户。

按照社会事件原型中第四阶段回看执行过程的用途，当前短时策略默认展示阶段明细，可切换日评估。这里不再沿用通用合并模板“结束后默认日评估”的显示选择；第五阶段单独承载最终汇总。这个原型的两个调价站都只执行一晚，所以切到日评估时只有 08/23 一个点，不硬连成跨天曲线。日评估点与原型最终累计值、基准值计算的变化率一致。

图表提供「阶段明细」查看。本地阶段明细沿用原型 12 点示例走势（progress 数组及百分比扰动），将时间重新映射到本站策略生效之后至 24:00，最后一个节点与最终日评估保持一致。该明细不是实际评估记录，页面标注「示例数据」，JSON 以 evaluationTimeline.stageSource 明确来源。原型原来的 08-21 至 08-23 18:00 时间早于策略生效，本版不再使用；正式接入必须由后端提供有效累计评估节点，不使用前端插值冒充真实记录。

原型顶部未提供统一的事件列表分析结论，本版不在全局事件信息中拼接某一站的结论；单站 AI判断始终跟随当前电站。

## 生命周期分组选中

03「决策生成」、04「决策执行评估」、05「决策复盘」在右侧导航固定共用一整块浅蓝选中背景，编号、名称、时间及各自锚点保持独立。点击任一项或滚动到该组时三项同步高亮；点击仍定位到对应卡片，抵达页尾后保留用户选定的锚点，不再强制切换到05。窄窗口上下排列时仍保持这一组，隐藏阶段不参与分组。01与02继续各自高亮，内容卡片的布局和时间不变。
