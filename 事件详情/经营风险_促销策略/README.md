### 原型与 PRD 差异的处理

- 原型核心卡为单日统计，趋势包含 08-11 至 08-17，因此明确标注「近 7 日趋势」，不把历史趋势称为本次累计分析期间。图例使用实际充电量、基线充电量；原型没有提供近 4 个可比周的数据，未把这一基线标成周均值。历史日期没有对应对比日期时，不拼接虚构日期。
- AI 修正保留原型的 08-16 回溯至 08-15；原型周末与工作日比较的原因描述不完整，使用「充电需求特征不满足可比条件」，不额外推定工作日筛选规则。
- 用户、渠道变化值按原型保留，影响占比按 PRD 的下降贡献口径展示为 100% / 0%。互联互通原型只展示「未严重下降」，保留定性描述，不把其占位数值当作实际零变化。
- 充电时段默认使用原型的三个时段与定性结果：18:00 至 22:00 下降最明显、08:00 至 13:00 明显下降、13:00 至 18:00 轻微波动。原型没有提供对应变化值和占比，因此展示「充电时段 / 定位结果」。不沿用调价 Demo 总计 -845 度的周期时段数据。
- 原型将竞品、价格都列为主因，并将设备列为次因；按 PRD 仅允许一个主因、最多一个次因，设备仅作参考。竞品优惠并入竞品判断，本站促销活动保留在排除因素，避免同一因素同时出现在参考与排除中。未补造竞品威胁分数、价格涨幅、调价次数或异常订单数量。
- 建议动作中的调价文本是原型遗留内容，已替换为该原型促销决策提供的活动配置。决策与复盘卡片已在下述最新修订中替换。
- 原型示例数字存在精度差异：用户变化合计 -185.805 度，核心变化为 -185.819 度；原型降幅显示 -12.29%，按其绝对值四舍五入为 -12.30%。此版保留原型显示值并与已完成的事件信息一致，正式接入时需统一统计与精度口径。
