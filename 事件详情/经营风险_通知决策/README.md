## 文件

- `经营风险_通知决策.html`：页面结构、核心趋势、异常定位及通知决策三组本地 JSON 数据。
- `style.css`：外壳、事件信息、分析过程与通知决策样式。
- `app.js`：趋势汇总与图表提示、AI 修正说明、时段列表滚动与展开、通知内容渲染、生命周期定位。
- `assets/`：本地 Logo、SVG 图标、Oswald SemiBold 字体；资源不跨 Demo 引用。
- `.history/creation/`：已有四个 Demo 的文件校验基线和本次验证记录。

HTML、CSS、JS 同级存放，不额外拆分 CSS/JS 文件夹，不引入构建工具。

## 页面结构

1. **事件信息**：8 个字段组成四列宫格，窄窗口两列；事件描述在宫格底部，AI分析结论在下方通栏展示，间距 8px。当前状态为「通知已发送」。
2. **分析过程**：核心指标、异常定位、分析因素、建议动作依次展示。核心指标与图表左右排列；异常定位默认三卡横排，时段内容溢出后可滚动或展开；因素沿用最多四卡一行、主次因素的影响指标置底、建议动作用无序列表的样式。
3. **决策生成**：独占一整行，上方四项为通知对象、渠道、时间、执行状态，下方直接预览完整通知内容。

PRD 5.2、6.1、8.5 明确通知策略的发送结果在03完成闭环，因此没有04评估复盘及相应导航。原型内未展示的调价执行、收益指标、复盘数据和接口模拟代码没有带入本 Demo。

保持 60px 顶栏、218px 左导航、220px 生命周期侧栏、12px 卡片内边距、14px 主模块间距、8px 内部模块间距。分析过程标题吸顶位于顶栏下方 12px；圆角遮挡层沿用已修复版本。标题横幅沿用淡蓝至透明渐变，标题下不加分割线；日期跨度使用「至」。

## PRD 与原型依据

- 通知决策原型（本地原型，不随仓库分发）。
- 事件详情 PRD（内部需求文档）：使用2026-09-14读取的文档，主要依据3.2、4.1、4.1.1、5.2、6.1和8.5。
- [AI管家UI风格规范](../../AI管家UI风格规范.md)与当前已确认的前四个 Demo，用户最新修订优先。

### 周期与数值

- 原型事件于2026-08-17触发，影响时间字段保持该日期；核心分析窗口是08-04至08-17。异常定位与因素沿用触发日数据，并在模块标题行标注「08-17 · 触发日」。不将单日影响电量当作14天总量。
- 14个日点直接取自通知原型 `mock.analysis.core.trend`。实际合计19,745.511度、基线合计21,440.660度、变化-1,695.149度、变化幅度-7.91%；8个日点降幅达到10%，与原型判断一致。汇总按千分之一度累加，避免浮点累计误差。
- 触发日实际充电量1,325.511度，对应修正后基线1,511.330度，减少185.819度；原型描述的185.81按三位小数统一。
- 核心卡保留原型的分析周期、时间范围、趋势结果、满足条件天数、周期变化值、周期变化幅度。图例额外展示原始日点汇总的实际和基线总量，满足PRD的实际/基线对比要求。
- AI修正仅展示原型能确认的修正后对比日期08-15及基线值，未补造初始候选日或不可比原因。原型未提供完整修正说明；正式数据应按PRD补齐。
- 异常定位的用户、渠道原始电量合计与事件核心数值相差0.014度，保留原始明细，不强行配平；正式接入需由业务统一口径。互联互通原型显示「未严重下降」，不把占位0解释为真实变化值。

### 因素分类与建议

- 原型同时标出两个主因和一个设备次因。按PRD4.1，仅允许一个主因素、最多一个次因素；按61.8%与38.2%排序，竞品为主因素、本站价格为次因素，保留114.8度与71.0度估算。
- PRD4.1.1第6类明确设备只作参考因素，因此去掉原型设备项的8.5%和15.8度，不将三类影响占比相加成108.5%。页面不附加规则说明文案。
- 原型「促销因素（本站）」被重复放在参考和排除中，参考正文却描述竞品限时优惠。竞品优惠并入竞品因素，本站促销保留为排除因素；天气、设备作为独立参考卡片。
- 用户和入口的影响占比按PRD的下降贡献口径展示100%/0%，不把增长用户的负贡献率用作下降占比。
- 建议动作与分析因素同级。保留通知建议及原型中的调价参考区间、日期；该调价内容是待评估建议，实际生成的策略类型是NOTIFICATION，不展示为已执行调价。

## 通知内容与交互

`notification-decision-data`提供通知对象「场站负责人、运营人员」、渠道「系统通知」、时间「2026-08-18 16:20:32」、结果「已发送」和完整文案。原型的一整段通知仅按语义拆成三段，未增加触达人数、已读率、送达回执或经营收益。

通知正文直接显示，满足内容预览需求；顶栏、左导航、返回和通知信息保持静态展示。生命周期点击定位、AI修正说明、趋势悬停/键盘焦点提示及长时段滚动/展开可操作。没有实际发送通知、确认决策、发券或调价的网络请求。

原型另有用户分布浮层示例，与前四个Demo一样，本版保留用户类别表格和PLUS影响结论，不扩展客户明细入口。
